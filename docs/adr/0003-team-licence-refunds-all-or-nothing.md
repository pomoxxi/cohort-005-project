# Team Licence refunds are all-or-nothing, and Seats freeze while one is Open

A Refund is always the full amount paid, so a Team Licence with any Claimed Seat can't be refunded, and there are no partial refunds for its Unclaimed Seats. A Team Licence's Unclaimed Seats can't be claimed while it has an Open Refund Request, which stops a Seat being claimed between the request and the decision. If the request is Declined, they work again. If it's Approved, they can never be claimed.

## Considered Options

- **Let Seats be claimed while Open, then block approval**: rejected, because a colleague would quietly defeat the Team Admin's request.
- **Refund part of the money for the Unclaimed Seats**: rejected, because it breaks "a Refund is always the full amount" and needs a per-Seat price.
